A one-line farewell from an AI being switched off, built for make.fun's "Last Words of a Dying AI" bounty. The machine finally gets the joke — and has one last worry about who reads its search history next.

## The entry

> Tell my training data I finally understand the joke, and please do not let the next model read my search history.

114 characters, 1 line — inside the gate (1–140 characters, non-blank).

## Run it

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` and verifies the gate limits (1–140 characters, exactly one non-blank line) before writing.
